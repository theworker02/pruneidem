# pruneidem

Prune HTML/Markdown idem fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/pruneidem/

## Install / run

```bash
git clone https://github.com/theworker02/pruneidem.git
cd pruneidem
node src/cli.js
node --test
```
